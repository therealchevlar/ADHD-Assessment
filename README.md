# ADHD Assessment & Clinical Reasoning Simulator

Educational React/Vite application demonstrating how ADHD assessment can be structured around the DSM-5-TR framework.

## Source basis
The diagnostic framework is based primarily on the American Psychiatric Association's *Diagnostic and Statistical Manual of Mental Disorders, Fifth Edition, Text Revision (DSM-5-TR)* (2022), especially the ADHD diagnostic criteria and accompanying diagnostic-features discussion.

The application is **not** a validated screening or diagnostic instrument and does not diagnose ADHD.

## Run

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
```

The production build is emitted to `dist/` for Vercel.
